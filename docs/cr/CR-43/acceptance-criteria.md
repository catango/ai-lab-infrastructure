# CR-43 Acceptance criteria

Verified by the implementation PRs of the plan and by settings checks that the approver runs. "Gate check" means a fixture test of a check in `scripts/checks/`, run by `./scripts/quality-gate.sh` (the `gate-tests` check) and by CI. "CI" means a green run of the named job. "Approver check" means a read-only check that the approver runs in the GitHub interface or with the operator tooling and records in the PR or the CR; Claude Code does not run it. The criteria are those of the approver's decisions of 2026-11-19 (design section 15) and become binding when the design PR is merged. They cover ADR-009 only; ADR-010 has its own.
